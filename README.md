# Pointcloud_Playground
This Repo Contains my modules on working with ROS2 pointcloud2 Data. Currently this repo is only tested witrh ROS2 Humble.

## pointcloud2_generator

A ROS 2 (Humble) Python package that publishes a universal, configurable
`sensor_msgs/PointCloud2` stream. 
For more infos see the [REAMDME.md](src/pointcloud2_generator/README.md).

## pointcloud_to_grid

A derivate of the original [pointcloud_to_grid](https://github.com/jkk-research/pointcloud_to_grid) Repo by [JKK-Research](https://github.com/jkk-research)
For more infos see the [REAMDME.md](src/pointcloud_to_grid/README.md).
